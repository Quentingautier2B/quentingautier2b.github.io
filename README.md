# Quentin Gautier — Portfolio
Lancer : `npm install` puis `npm run dev` (http://localhost:5173). Production : `npm run build` (dossier `dist/`, déployable sur Netlify / Vercel / GitHub Pages).
- Projets : `src/data/projects.ts` — Images : déposer dans `public/images/` et renseigner `cover` / `images` (ex. `/images/micromega-1.jpg`).
- Textes FR/EN : `src/i18n.ts` — Contact : `src/config.ts` — Image de partage : `public/og-image.png` (1200×630).
